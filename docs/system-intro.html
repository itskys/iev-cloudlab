系统架构 System Architecture

六层架构：接入层（Cloudflare）→ 平台层（JupyterHub）→ 实验层（29个实验）→ 支撑层（共享库/场景/数据）→ 仿真引擎层（全部真实开源引擎）→ 教学管理层（自动评分与教师面板）。

数据流与工作流 Data Flow & Workflows

功能特色 Features

🧪 真实仿真

esmini、SUMO、FASTSim、PyBaMM 等真实引擎逐一实测验证；演示性内容强制标注，绝不以假充真。

🔗 全链打通

实验不是孤岛：换一块电池、改一个车型参数，下游整车与智驾实验自动跟随。

📚 教学完整

每个实验含原理、目的、任务、验证、结果分析、报错说明六段式与原理图，配学生指南、教师手册与 16 周大纲。

✅ 自动评分

29 套判据阈值全部取自实测值，带防作弊设计；教师面板提供成绩、统计、图表与名册管理。

☁️ 弹性云原生

Cloudflare 门面 + 容器隔离，按需扩容；GPU 感知层（CARLA / Autoware）已为二期预留。

🔓 全开源

工具链全部开源并完成 31 项许可证审计，无商业授权风险。

实验一览 Experiments

  • A 自动驾驶（5）：AEB 紧急制动、ACC 跟车、交叉口让行等场景闭环测试
  • B 交通流（5）：跟车模型标定、信号优化、CACC 编队、拥堵波、绿波协调
  • C 整车能量（4）：百公里电耗、车型对比、灵敏度、能量管理策略
  • D 电池（4）：充放电特性、倍率容量、OCV 标定、快充析锂
  • E 优化控制（4）：单/多目标优化、MPC 跟车、动态规划能量管理
  • F 模型交换（3）：FMU 加载、建模导出、多模型协仿真
  • G 中间件（2）：ROS 2 话题通信与服务调用
  • H 场景工程（2）：场景批量生成、变异模糊测试
诚实边界：感知层（相机/激光雷达）与完整自动驾驶栈属二期（需 GPU）；A 系列中 esmini 目标车在 ctypes 模式下为冻结状态（等价静态障碍物），已在每个受影响实验中如实声明。
