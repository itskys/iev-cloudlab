系统架构 System Architecture

六层架构：接入层（Cloudflare）→ 平台层（JupyterHub + 算力沙箱）→ 实验层（29个 V1.0 标准实验 + 期末 Capstone + 智能学习驾驶舱）→ 支撑层（共享算法库/场景库/数据流）→ 仿真引擎层（全部真实开源物理引擎）→ 教学管理层（自动评分、学生驾驶舱与教师学情面板）。图中虚线框为二期规划。

数据流与工作流 Data Flow & Workflows

核心理念是「任一入口进，全链路出」：数据沿四条链在实验间流动——车型设计链（电池标定→整车能耗→智驾测试）、算法开发链（控制器→闭环→指标→调参）、能量管理链（优化→验证→成绩单）、感知链（二期规划）（CARLA/AWSIM三维场景→传感器数据→YOLO目标检测与融合→Autoware完整驾驶栈）；成绩则经自动汇总与评分引擎流向教师面板。

功能特色 Features

🔗 四大跨域数据链

车型设计链、算法闭环链、能量管理链与感知链贯通；换一块电池或改一个参数，下游自动跟随响应。

📚 严谨六步导学

数理推导、算法实现、闭环仿真、3D孪生、参数探索与自动化评测六段式，配全套教研资源。

学生端提供七维能力画像与 Copilot 调参驾驶舱；教师端提供班级总评、AST 代码查重与报告核验。

☁️ 弹性云原生沙箱

Cloudflare 门面 + 容器秒级隔离就绪，独立单人配额，数据持久化自动同步。

🔓 宽松开源许可证

实验一览 Experiments

  • A 自动驾驶（5）：AEB 紧急制动、ACC 跟车、交叉口让行等场景闭环测试
  • B 交通流（5）：跟车模型标定、信号优化、CACC 编队、拥堵波、绿波协调
  • C 整车能量（4）：百公里电耗、车型对比、灵敏度、能量管理策略
  • D 电池（4）：充放电特性、倍率容量、OCV 标定、快充析锂
  • E 优化控制（4）：单/多目标优化、MPC 跟车、动态规划能量管理
  • F 模型交换（3）：FMU 加载、建模导出、多模型协仿真
  • G 中间件（2）：ROS 2 话题通信与服务调用
  • H 场景工程（2）：场景批量生成、变异模糊测试
  • 🏆 期末大作业 (Capstone)：多物理场跨域一体化综合实验（电池机理 × FASTSim能耗 × ACC控制 × 3D数字孪生）
  • 📊 智能学习驾驶舱 (Student Cockpit)：学生自主画像、七维能力雷达图、IEV Copilot 智能导师与结课作品集导出
  • I 感知与自动驾驶（5，二期·GPU）：CARLA三维场景与传感器、YOLO目标检测、点云与融合、定位规划、Autoware完整驾驶栈——经 GPU 算力舱（RunPod 4090）按需运行
诚实边界：I 系列（感知与完整自动驾驶栈）为二期规划、尚未上线，图中以虚线框标注；A 系列中 esmini 目标车在 ctypes 模式下为冻结状态（等价静态障碍物），已在每个受影响实验中如实声明。
