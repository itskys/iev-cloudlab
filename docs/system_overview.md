# IEV CloudLab 系统功能与特色总览
# System Overview

> 配套图：`fig1_architecture.png`（系统架构图）、`fig2_dataflow.png`（数据流与工作流图）

## 一、系统定位

**智能电动汽车云仿真实验平台**：学生用浏览器（零安装）完成智能电车的设计、仿真、优化与验证实验。核心理念：**任一入口进，全链路出**——从电池、整车、算法任一模块开始，数据沿三条链打通。

## 二、功能清单（对照架构图）

| 层 | 功能 |
|---|---|
| 接入层 | Cloudflare Tunnel/DNS/CDN，公网 https://ievlab.aisai.cc，学生零安装 |
| 平台层 | JupyterHub 5.5.3；邮箱验证码登录（学校域名自助注册）；每人独立容器 |
| 实验层 | 29个实验，8大模块（A自动驾驶/B交通流/C整车/D电池/E优化/F模型交换/G-ROS/H场景工程）；每实验六章节+原理图+双语 |
| 支撑层 | 共享库（控制器/环境/适配器/车辆库/原理图库）、标准场景库、协同数据库（车型/电池/结果） |
| 引擎层 | 全部真实开源引擎：esmini、SUMO、FASTSim、PyBaMM、CasADi、pymoo、FMPy、ROS 2 |
| 管理层 | 自动评分（29判据，实测阈值）、教师面板（成绩/统计/图表/名册/归档）、成绩每小时自动汇总 |

## 三、数据流（对照数据流图）

- **链1 车型设计链**：D3电池标定 → OCV曲线 → C1整车能耗 → 车型参数 → A系列智驾测试（换车型，智驾自动跟随）
- **链2 算法开发链**：控制器 → A/B闭环 → 指标（TTC/误差/PET）→ 调参迭代
- **链3 能量管理链**：E优化 → 最优策略 → C4整车验证 → 成绩单
- **成绩流**：学生存结果 → 每小时汇总 → 评分引擎 → 教师面板（表格/统计/图表）

## 四、工作流

- **学生**：登录 → 选实验 → 读原理（+原理图）→ 运行调参（试一试）→ 自查评分 → 写报告
- **教师**：建名册（添加/CSV导入）→ 按三链授课 → 看成绩与图表 → 定位薄弱实验 → 结课归档

## 五、特色

1. **真实仿真**：全部真实引擎实测验证；替身演示强制标注；已知限制（esmini目标车冻结等）如实声明——诚实是设计原则
2. **全链打通**：实验不是孤岛，数据沿三链流动，改一处、全链受益
3. **教学完整**：原理/目的/任务/验证/分析/报错六段式 + 工程背景 + 设计改进思考 + 配套学生指南/教师手册/16周大纲
4. **自动评分**：判据阈值=实测值，带防作弊（最小步数判据+超时看门狗）
5. **弹性架构**：Cloudflare门面 + 廉价VPS + 容器隔离；GPU感知层（CARLA/Autoware）为Stage 2预留
6. **全开源**：31项许可证已审计，无商业授权风险

## 六、边界（诚实声明）

- 感知层（相机/激光雷达）与完整自动驾驶栈未含（需GPU，Stage 2）
- A1-A4的esmini目标车在ctypes模式下冻结（等价静态障碍物，已标注）
- 新学生账号自助注册后，实验文件需预置（试点期由管理员批量分发）
