# IEV CloudLab 学生快速上手指南
# Student Quickstart Guide

## 一、登录 | Login

1. 打开 https://ievlab.aisai.cc
2. 输入学校邮箱（`@zhjpec.edu.cn`）
3. 点击"发送验证码"，查收邮件（6位数字，10分钟有效）
4. 输入验证码，点击登录

> **注意**：验证码每小时最多发送5次。如果没收到，先检查垃圾邮件。

## 二、界面 | Interface

登录后进入JupyterLab，左侧文件浏览器可见：
- `notebooks/` — 29个实验（按A-H模块组织）
- `labs/` — 实验支撑文件（一般不用直接打开）

## 三、运行实验 | Running Experiments

### 3.1 打开Notebook
双击 `notebooks/A1_cutin_aeb.ipynb` 打开。

### 3.2 选择内核 | Select Kernel
**重要**：C系列和E系列需切换内核：
- 右上角点击内核名称 → 选择 `py310-fastsim`
- 其他模块用默认 `Python 3`

| 模块 | 内核 |
|---|---|
| A, B, D, F, G, H | Python 3 (默认) |
| C, E | py310-fastsim |

### 3.3 运行
- 逐个运行：点击代码格，按 `Shift+Enter`
- 全部运行：菜单 `Run` → `Run All Cells`
- 首次运行C/E模块需等待约30秒（加载FASTSim）

### 3.4 阅读顺序
每个实验按以下顺序阅读：
1. **一、实验原理** — 先理解公式和物理意义
2. **二、实验目的** — 明确要学什么
3. **三、学生任务** — 动手做（有思考题和挑战）
4. **四、验证内容** — 对照检查是否达标
5. **五、结果分析** — 理解数据背后的意义
6. **六、常见报错** — 出错时查这里

## 五、常见问题 | FAQ

**Q: 图表中文显示为方框？**
A: 正常。matplotlib暂无中文字体，所有图表标签用英文。这是已知限制，不影响学习。

**Q: 内核一直启动中？**
A: 等待2分钟。若仍不行，菜单 `File` → `Hub Control Panel` → `Stop My Server` 后重进。

**Q: 代码报错？**
A: 先看该实验"六、常见报错说明"，有中文解释。90%的问题那里都有答案。

**Q: 结果和文档中的数字不一样？**
A: 小幅差异正常（随机种子、数值精度）。大幅差异先检查参数是否改动过。
