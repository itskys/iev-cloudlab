# IEV CloudLab 学生快速上手指南 | Student Quickstart

> 这份指南只讲**操作**：怎么登录、怎么打开实验、怎么知道自己做对了、出问题怎么办。
> 实验内容与合格标准看《实验手册》；本指南不重复。

## 一、登录（约1分钟）

1. 浏览器打开 **https://ievlab.aisai.cc**
2. 在登录框输入你的**学校邮箱**（@zhjpec.edu.cn），点"发送验证码"
3. 去邮箱收 6 位验证码（可能在垃圾箱里，第一次务必检查），填入并登录
4. 首次登录会启动你的专属实验环境，需要等 **30–60 秒**，页面转圈是正常的，不要刷新
5. 看到左侧文件列表 = 登录成功。以后每次登录都会回到你自己的文件，之前做的实验都还在

⚠️ 验证码10分钟内有效、只能用一次；1小时最多发5次，收不到先查垃圾箱，不要连点发送。

## 二、认识界面（30秒）

- **左侧**：文件列表。`notebooks/` 包含 29 门 V1.0 官方标准实验（命名为 `*_pro.ipynb`）、1 项期末综合大作业（`Capstone_iev_integrated_pro.ipynb`）以及学生工程驾驶舱；`labs/` 是平台核心物理模型共享库（**只看不要改**，改了会影响你所有实验）
- **中间**：打开的实验文件（.ipynb）。每个实验由一段段"单元格"组成：灰色的是说明文字，白色代码框是要运行的程序
- **右上角**：当前内核名称——**这是最重要的一个位置**，见第五节

## 三、三轨学习模式选择：直觉、仿真与量产 C 代码

平台为不同阶段的学习需求提供三条贯通路径：
1. **轨 1 · 新手直觉探索 (Phase 0 / Lite · 零门槛物理建模)**：
   - **适合场景**：刚开始上课、想先直观感受物理现象与控制规律。
   - **操作方式**：打开全套 30 门实验（`*_pro.ipynb`）任意一门顶部的 **Phase 0 直觉探索驾驶舱**：
     - **🎯 一键典型工况快照 (Preset Buttons)**：每个探索器顶部均标配 3~4 个典型工程工况按钮（如 A1 的“激进加塞 (TTC=1.8s)”、“极限制动 (TTC=2.4s)”、“稳健安全 (TTC=3.2s)”；D4 的“极寒未预热强充致析锂”、“热管理预热后安全嵌锂”等），点击即可瞬间载入具有鲜明物理特性的极限/基准参数组合；
     - **📐 主机厂量产工程对标徽章 (Benchmark Badges)**：直观展示行业参考规范与教学量规（如 Euro NCAP 2023 CCRs、ISO 15622、SAE J1634、GB 38031、ISO 26262 ASIL-D 等）；
     - **实时滑杆调参 + 动力学机理曲线**：拖动滑块即可即时刷新响应曲线；
     - **微任务预习打卡**：在底部文本框填写你的物理直觉心得，点击打卡保存。无需写代码，不计入正式成绩。
   - 另提供 5 门独立 Lite 体验本（A1/B2/C1/D1/E3 的 `*_lite.ipynb`），零代码体验真仿真引擎。
2. **轨 2 · 工业仿真进阶 (Simulation Pro · 课程必做)**：
   - **适合场景**：完成 16 周教学大纲要求、获得学分的标准路径。
   - **操作方式**：在 `notebooks/` 下打开 `*_pro.ipynb`，从上至下按顺序运行代码、调优参数、通过判据，并在末尾保存成绩、撰写实验报告。
3. **轨 3 · ⚡ MISRA-C 量产嵌入式轨 (Production C Track · 进阶挑战)**：
   - **适合场景**：对汽车电子、VCU/BMS/智驾域控底层开发感兴趣，或想冲击高分与优秀工程能力画像。
   - **核心内容**：在 **A1 (AEB多级制动FSM)、A3 (CCRb增强TTC与液压滞后)、B1 (5车弦稳定CACC编队)、C4 (HEV混动四模态EMS与滞环)、D3 (BMS库仑RC观测器与OCV校准)、E3 (MPC紧缩QP PGS求解器)** 这 6 门实验中，滑到中后部的「⚡ MISRA-C 量产级 C 代码对照」章节。点击即可在容器内由 `gcc -O2` 编译纯 C 动态库，并完成微秒级单步耗时与 Python 版本的异构对齐验证（实测值见各本 §7.3）！在实验报告中对比两者的执行效率与量产约束，可获课程附加分并点亮工程画像中的量产徽章。

## 四、开始第一个实验（手把手，以A1为例）

> 💡 **零代码先行**：每本 Pro 顶部都有阶段零探索（滑杆 + 按钮，不用写代码）；A1/B2/C1/D1/E3 另有独立 lite 新手本（`*_lite.ipynb`），只写完成记录、不进成绩册；三档总览见《新手模式总览.md》。建议第 1 周先玩阶段零 / lite 本建立直觉，再按下面步骤跟跑完整实验。

1. 左侧双击 `notebooks/` → 双击 `A1_cutin_aeb_pro.ipynb`（V1.0 官方标准实验）
2. **先通读开头的说明文字**：实验原理、诚实声明、实验目的——不读说明直接跑，做完也不知道自己做了什么
3. 从上到下**逐格运行**：点中一个代码格，按 `Shift+Enter` 运行并跳到下一格。**不要跳格**，后面的格子依赖前面的结果
4. 每格左侧出现 `[数字]` = 运行完成；出现红色报错 = 停下，先看第七节自查表
5. 跑到"验证内容"一节：逐项核对清单，这就是老师判你对错的标准
6. 跑完最后一格（保存结果）——**没有这一步，系统里就没有你的成绩**
7. 做"🔬试一试"：改1个参数 → 从该格往下全部重跑 → 把参数和结果记到实验报告里
8. *(可选挑战)* 体验「⚡ MISRA-C 量产级 C 代码对照」单元格，观察微秒级单步的硬实时性能！

**成功的标志**：A1你会看到一张TTC曲线图，最小TTC大于1.5秒、没有碰撞提示。每个实验的判据数值在《实验手册》对应条目里，跑完自己对一遍。

## 五、内核：最重要的一条规矩

右上角的内核选错，是本平台**第一大报错来源**，没有之一。

| 实验模块 | 必须选的内核 |
|---|---|
| **C、E 模块** | **py310-fastsim** |
| A、B、D、F、G、H 模块 | Python 3 (ipykernel) |

切换方法：点右上角内核名称 → 在列表里选。**打开C/E实验的第一件事就是切内核**，养成习惯。如果报错信息里出现 `No module named 'fastsim'`，99%是内核没切。

## 六、四大硬核汽车工程深度机理可视化解读指南

平台在关键实验与驾驶舱中内嵌了四大汽车工业级深度机理动态可视化组件，帮助学生建立深层物理直觉：

### 1. C1 FASTSim 整车动力学电耗能量流向瀑布图 (Energy Waterfall)
- **展示位置**：`C1_fastsim_energy_pro.ipynb` Phase 0 探索器与仿真结果区。
- **物理机理分解**：图表清晰呈现从电池释放总电能到车辆克服环境阻力的能量级联分解：
  - `电池端净放电 (Net Battery Output)` $\to$ `电机与逆变器损耗` $\to$ `变速箱传动损失` $\to$ `滚动阻力损耗` $\to$ `空气阻力损耗` $\to$ `制动动能回收 (Regen Braking)`。
- **工程分析方法**：对比城市工况（UDDS）与高速工况（HWFET）：城市工况下反复启停导致频繁的动能加减速与回收，整车质量对电耗起决定作用；而在高速工况下，风阻消耗能量随车速平方急剧攀升，风阻系数 $C_d$ 成为能耗核心矛盾。

### 2. A1 BEV 鸟瞰激光测距动态标尺与急刹滑移胎痕 (LiDAR Ruler & Skid Marks)
- **展示位置**：`A1_cutin_aeb_pro.ipynb` Phase 0 动态重放画布。
- **视觉要素说明**：
  - **高精激光测距虚线 (LiDAR Ruler)**：自车前向雷达自动向切入目标车发射动态测距标尺，实时标注距离（米）与 TTC 时距。标尺颜色按距离两色区分：红色（近距，< 10m）、蓝色（其余）；HUD 的 TTC 文字另按三色显示：绿色（TTC ≥ 3.0s）、黄色（1.5s ≤ TTC < 3.0s）、红色（TTC < 1.5s）；
  - **地面急刹滑移胎痕 (Skid Marks)**：当 AEB 触发高减速度制动（$a < -3.5\text{m/s}^2$）时，自车左右后轮轨迹实时绘制出黑色滑移胎痕，直观展现地面附着摩擦极限（胎痕为制动示意，不标注数值）。

### 3. D4 PyBaMM 一维 Newman 极板电位梯度与析锂沉积轮廓 (Lithium Dendrite Profile)
- **展示位置**：`D4_lithium_plating_pro.ipynb` Phase 0 探索器与微观电化学分析区。
- **物理机理分解**：
  - **一维 Newman (P2D) 固液电位梯度曲线**：沿电池厚度方向（负极 $\to$ 隔膜 $\to$ 正极）展示固相电位与液相电位差值 $\Phi_s(x) - \Phi_e(x)$；
  - **析锂临界红线 ($0.00\text{V}$)**：当大倍率（如 3C）充电或低温环境下，锂离子固相扩散速率严重低于电化学还原速率，负极靠近隔膜界面处的电位率先跌破 $0\text{V}$，触发析锂副反应；
  - **析锂枝晶微观沉积厚度轮廓**：下方同步展示金属锂枝晶沉积厚度空间分布图，直观展现导致电芯内短路与热失控的微观物理演变。

### 4. 学生工程驾驶舱：跨域学习路径全景 DAG 拓扑图 (Learning-Path DAG)
- **展示位置**：`学生面板_学习驾驶舱与工程自检.ipynb`。
- **三链贯通拓扑**：
  - **🔋 链 1：动力电池与整车能耗链**（`D3 标定电池` $\to$ `C1 整车能耗` $\to$ `C4 混动ECMS` $\to$ `Capstone 综合总成`）；
  - **🚗 链 2：智驾极限感知与规划控制链**（`H1 加塞场景生成` $\to$ `A1 AEB避碰` $\to$ `A2 ACC巡航` $\to$ `E3 MPC优化` $\to$ `Capstone 轨迹跟踪`）；
  - **🌐 链 3：交通流与编队协同链**（`B1 IDM标定` $\to$ `B3 编队弦稳定` $\to$ `B4 冲击波` $\to$ `B5 绿波带` $\to$ `Capstone 全域调度`）。
- **节点状态含义**：绿色填充（已达标）、黄色填充（已完成但指标需重整）、白色虚线（待攻坚）。通过连线上的数据资产标签（如 `ocv_soc_export.json`, `cutin.xosc`, `ecms_opt.json`）直观理解学习顺序；仅 D3→C1 有校验链路，其余连线不代表数据自动流转。

每个实验末尾都有自查环节，跑完你会立刻知道自己是否达标：
- 看到 ✅ 和分数 = 已保存、已判分；
- **若分数 < 60 或未通过**：系统会自动在评分卡下方展开 **IEV Automotive Diagnostic Tutor（汽车工程智能伴学与失效归因导师）** 看板：
  - **🚨 致命失效 / ⚠️ 性能超标标签**：明确指示哪项动力学或电化学判据未达标；
  - **🔍 物理与控制第一性原理因果剖析**：不仅告诉你错了，更深入剖析物理公式（如运动学制动冲量方程、时延闭环传递函数幅值上界 $\|H(j\omega)\|_\infty > 1.0$、Newman 过电位极化机理等），指出系统失稳根因；
  - **🎛️ 结构化推荐调参处方矩阵 (Tuning Matrix)**：给出待调整参数名、当前估计值、调节方向（增大/减小）、建议调节步长与主机厂量产推荐区间；
  - **🏭 主机厂量产工程对标规范**：标注 Euro NCAP 2023、ISO 15622、SAE J3161/1、GB 38031 等行业参考规范，让你的调参参考量产工程实践。

## 八、报错与进阶工具自查表（先自查，再求助）

| 报错/需求 | 原因/场景 | 怎么办 |
|---|---|---|
| 调参陷入瓶颈/碰撞报警 | 对物理机理与参数边界不熟悉 | 运行该实验底部的 **IEV Copilot 智能助教** 单元格，Copilot 会根据物理制动距离方程或电化学约束给出专业机理诊断与调优处方 |
| 代码改乱了想回滚 | 误删代码或改崩了算法 | 运行底部的 **代码时光机 (Time Machine)** 组件，点击对应时间点的快照即可一键回滚或查看代码 Diff |
| 想参与班级挑战比拼 | 实验调优达到极致想看班级排名 | 在 A1、B3、E4、Capstone 实验末尾运行 **天梯榜 (Leaderboard)** 单元格，提交你的能耗或制动指标，在个人学习驾驶舱查看自己的历史最佳与进度（当前排行榜仅记录个人成绩，不做全班排名） |

| 报错/现象 | 原因 | 怎么办 |
|---|---|---|
| `No module named 'fastsim'` | C/E模块内核没切 | 切 py310-fastsim 内核，重启内核后从头跑 |
| `No module named 'common'` | 跳格了，或文件不在notebooks目录打开 | 关掉，从 notebooks/ 里重新打开，从第一格顺序跑 |
| `FileNotFoundError: ...csv/.yaml` | 同上，多为跳过了加载格 | 从加载数据的那一格开始顺序重跑 |
| 图里中文是方框□□ | 平台绘图字体限制，**不是你的错** | 图的标题/标签看英文即可，报告里用中文写图题说明 |
| 改了参数，结果和图没变化 | 只重跑了改参数的格子 | 从改动处往下**全部**重跑（运行 → 重新启动并运行全部也可） |
| 一直转圈/环境打不开 | 首次启动慢，或浏览器缓存旧了 | 等满60秒；还不行就关掉标签页重新进，或换无痕窗口 |

| 运行到一半内核"死了" | 内存超限（多见于同时开很多实验） | 关掉不用的实验标签页，重启内核再跑 |

## 九、实验报告怎么写（老师按这个给分）

每个实验交一份简短报告（模板跟老师要），必须包含：
1. **结果**：关键数值（带单位）+ 判据是否通过。数值必须是你自己跑出来的
2. **图**：至少核心结果图，图下面写一句话图题（如"图1 UDDS工况电耗构成"）
3. **分析**：用自己的话解释——这个数值说明什么？和理论/手册量级比怎么样？误差可能来自哪？
4. **思考题回答**：实验末尾的问题，这是拉开分数差距的部分
5. **试一试记录**（做了才写）：改了什么参数 → 结果怎么变 → 你得出的结论

⚠️ 直接抄《实验手册》里的"实测值"当自己的结果，是本课程最容易被发现的作弊——平台保存着你每次运行的真实结果文件，老师一对就知道。
