# IEV CloudLab 课程大纲（16周）
# Syllabus

## 课程信息

- **课程名称**：智能电动汽车仿真实验
- **学时**：48学时（16周 × 3学时）
- **先修**：Python基础、汽车构造、自动控制原理
- **平台**：https://ievlab.aisai.cc

## 教学目标

1. 掌握车辆动力学、电池、交通流的基础仿真方法
2. 理解ADAS（AEB/ACC）的工作原理与评价方法
3. 掌握多目标优化、MPC、动态规划在汽车中的应用
4. 了解FMI、ROS 2、场景工程等工业界工具链
5. 培养"真实仿真、诚实报告"的工程素养
