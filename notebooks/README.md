## 如何使用本手册

每个实验条目包含五项：
- **做什么**：一句话目标 + 核心任务
- **判据**：自动评分的合格线（括号内为平台实测参考值；你的结果应落在同一量级）
- **难度 / 时长**：★入门 ★★进阶 ★★★综合；时长为建议学时（45分钟/学时）
- **前置**：建议先完成的实验（无=可直接开始）
- **内核**：打开实验后右上角须切换的运行内核（选错会报模块找不到）

实验文件命名规则：**字母=模块，数字=模块内顺序（难度与依赖递增）**，文件浏览器里的排列顺序就是推荐学习顺序。

## 三条链（实验之间的数据流，只在此处定义）

实验不是孤岛。下列三条链是课程的骨架，教师按链授课、学生按链理解：

**链1 · 车型设计链**：`D3 输出的电池CSV` → `C1/C2 加载（BatteryFASTSimAdapter）算整车能耗` → `车型YAML 的动力学参数` → `A1–A4 的自车模型`。
动手验证：把D3的电池换个标定参数重跑，C1电耗会变，A系列自车加速度随之变——"换车"不是改个名字。

**链2 · 算法开发链**：`common.BaseController` → `A/B 闭环仿真` → `指标（TTC/间距误差/PET）` → `改参数再跑`。
A2的PD参数、B3的编队控制、E3的MPC权重都走这条链：先有指标，才谈得上调参。

**链3 · 能量管理链**：`E4 动态规划全局最优（1.92）` → 作为标杆 → `C4 三种工程策略（CD/CS/ECMS-like）与之对比` → 理解"最优"与"可实现"的差距；E1/E2的优化结果同样回到FASTSim复核。

另有**成绩流**：每个实验运行后自动保存结果 → 平台每小时汇总 → 自动评分（判据即本手册所列）→ 教师面板。
